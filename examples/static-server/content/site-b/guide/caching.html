How this server caches

  • ETags are content hashes. Same bytes, same validator — no matter which source served them, or when the archive was built.
  • HTML revalidates every time (max-age=0, must-revalidate), so a page is never stale, and a 304 costs one round trip and no body.
  • Fingerprinted files are immutable for a year. app.9f2c1a7d.js cannot change without changing its name, so it never needs revalidating.
  • Everything else is fresh for an hour by default, then revalidated.
